2. Description of Service

BIMSCOPE is a free, browser-based IFC (Industry Foundation Classes) viewer and inspector tool. The Service allows users to:

  • Load and view IFC model files in 3D directly in the browser
  • Inspect element properties, property sets, and type properties
  • Analyze rooms, spaces, and building storeys
  • Export structured data in JSON and CSV formats
  • View model summaries and per-floor analytics

All file processing occurs entirely within your web browser. No data is uploaded to or stored on our servers.
